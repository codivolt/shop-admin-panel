# Admin Panel - React + Vite + Tailwind CSS

## Structure
- src/design-system/ - theme tokens (colors, fonts, spacing, etc.)
- src/pages/ - page components
- src/components/ - reusable components
- src/config.ts - API configuration

## Themes
Edit `src/design-system/tokens.ts` to change colors, fonts, spacing, etc.

## Run
```
pnpm install
pnpm run dev
```

Server runs on http://localhost:3001
